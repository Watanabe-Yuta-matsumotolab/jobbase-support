本ポリシーは、iOSアプリ「就活Base」における情報の取り扱いについて説明します。

端末内に保存する情報

就活Baseは、利用者が入力した企業情報、選考情報、予定、タスク、メモ、整理ノート、面接記録、ES、ボードなどの就職活動情報を原則として端末内に保存します。アプリ専用アカウントの登録は必要ありません。

これらの就職活動情報を開発者のサーバーへ送信・収集しません。独自のCloud同期や外部AI APIは使用していません。企業情報・メモ・ES・採用サイトのIDやパスワードの内容を広告SDKへ渡すこともありません。

広告と広告に関する情報

Version 1.0.0 Build 24以降では、ホームと企業一覧にGoogle AdMobのバナー広告を表示します。Build 23以前にはこの広告SDKを搭載していません。

広告配信のためGoogle Mobile Ads SDKとGoogle User Messaging Platform（UMP）を使用します。Googleは、IPアドレスから推定されるおおよその位置、端末またはアプリに関連する識別子、広告の表示・操作情報、クラッシュ・パフォーマンスなどの診断情報を取得する場合があります。これらは広告配信、広告の測定、不正防止、サービス改善などに利用されます。アプリには別途Google AnalyticsやFirebase Analyticsを導入していませんが、広告SDK自体による測定・解析が行われる場合があります。

アプリから要求する広告のパーソナライズとPublisher first-party IDを無効にしています。アプリから広告トラッキング許可（ATT）を要求しません。非パーソナライズ広告でも、広告配信に必要な情報の取得がなくなるわけではありません。

対象地域やGoogleの設定に応じてUMPが必要な同意画面を表示します。広告の設定変更が必要な場合は「その他 → アプリについて → 広告のプライバシー設定」から選択を変更できます。広告を取得できない場合も、企業・予定・メモなどの機能は利用できます。

Googleが取得する情報の保持・削除などはGoogleの規定に従います。アプリのデータ削除操作は、Googleが取得した情報の削除を意味しません。詳しくはGoogleのプライバシーポリシー、Googleの広告に関する説明をご確認ください。

採用サイトの認証情報

利用者が登録したログインID・パスワードはAppleのKeychainを利用して端末内に保存します。パスワードの表示等ではFace IDまたは端末パスコードによる本人認証を利用します。アプリが顔画像や端末パスコードを取得することはありません。

ID・パスワードはアプリのバックアップファイルには含まれません。別端末では再入力が必要です。

保持・バックアップ・共有

入力した情報は、利用者が削除するまで端末内に保持されます。自動・手動バックアップおよび復元前バックアップはアプリの保存領域に保持され、保存世代数に応じて古いバックアップが整理されます。

利用者の操作で情報をJSONファイルに書き出し、任意の保存先や共有先へ送ることができます。ファイルにはメモやESなどが含まれるため、保存先と共有相手をご確認ください。iOSの端末バックアップにはAppleの設定・サービス条件が適用されます。

データの削除

保存した項目はアプリ内の削除操作で削除できます。企業削除に伴う関連情報の削除・関連解除の範囲は、アプリの確認画面で確認できます。

「全データ削除」では端末内バックアップは残るため、不要なバックアップは一覧から別途削除してください。アプリを削除するとアプリの保存領域と端末内バックアップは削除されます。アプリ外へ書き出したファイルは保存先から別途削除してください。アプリの削除だけでKeychainを含むすべての情報が削除されるとは限りません。

外部リンクとWebサイト

外部サイトへアクセスした場合、そのサイトでの情報の取り扱いにはリンク先事業者のプライバシーポリシーが適用されます。

このサイトはGitHub Pagesで配信します。サイト独自の広告・アクセス解析・追跡用スクリプトは使用しません。ホスティングに伴う情報の取り扱いについてはGitHubのプライバシーステートメントをご確認ください。

通知

通知を許可すると、予定やタスクのリマインダーを端末に表示します。許可はiOSの設定から変更できます。

ポリシーの更新

情報の取り扱いに変更がある場合、本ページの内容と最終更新日を更新します。
